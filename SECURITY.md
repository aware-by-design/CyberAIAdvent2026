# Security policy

Please report security problems privately using GitHub's private vulnerability reporting: open https://github.com/aware-by-design/CyberAIAdvent2026/security/advisories/new, fill in the form and select **Submit report**. You need to be signed in to GitHub.

Only the people who look after the calendar can see your report. Please don't report security problems in public issues, pull requests or discussions.

How private reporting works: https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately
